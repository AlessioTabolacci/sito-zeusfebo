# Sito ufficiale ZeusFebo — prima versione

Homepage responsive realizzata con HTML5, CSS3 e JavaScript puro. Non usa
framework, librerie esterne, cookie o servizi di terze parti.

## Come aprire il sito

Il metodo consigliato è avviare un piccolo server locale:

1. Apri il Terminale.
2. Entra nella cartella `sito-zeusfebo`.
3. Esegui `python3 -m http.server 8000`.
4. Apri `http://localhost:8000` nel browser.
5. Per fermare il server, torna nel Terminale e premi `Ctrl + C`.

In alternativa puoi aprire direttamente `index.html`, ma il server locale
simula meglio il funzionamento di un vero sito.

## Dove modificare i contenuti

- `index.html`: testi, date, titoli, link e contenuti delle sezioni.
- `css/style.css`: colori, dimensioni, spazi e aspetto grafico.
- `js/script.js`: menu mobile, animazioni e comportamento allo scorrimento.
- `assets/images`: fotografie e copertine ufficiali.
- `assets/audio`: eventuali anteprime audio autorizzate.
- `assets/icons`: favicon e altre icone.

## Prima della pubblicazione

Sostituire tutti i testi marcati come provvisori, inserire immagini ottimizzate
in WebP o AVIF, aggiornare i link social e musicali, correggere i dati Open
Graph nell'`<head>` e verificare di possedere i diritti per ogni contenuto.
